1hEVA system — components · states · rules

EVA component inventory

  • EvaMark — 4-point spark in a 26px bordered circle. States: idle (static), thinking/streaming (1.6s opacity pulse), muted (grey, interrupted). Never larger than 44px, never animated outside active states.
  • Composer — pill (empty state, mobile) or expanding card (with attachments). Attach + Send; Send at 45% opacity until input exists.
  • AttachmentChip — composer (removable) and sent-message (read-only) variants.
  • RecommendationCard — label + title / 2–4 labelled rows / actions. Max-width 560px so it never spans the full thread.
  • ArtifactChip — icon + name + "Saved to …" + Open. The handoff primitive for Campaign and Creative.
  • ContextChips — read-only pills showing what EVA is reusing (campaign, offer, asset, voice).
  • StopButton / ErrorNotice / InterruptedNote — as in 1e.

Spacing & type

Thread max-width 760px, centred. Message gap 24–28px (18px mobile). Body 15px/1.65 (14.5 mobile); card labels 11px/600 caps +0.07em; card body 14px. User bubbles max 75% width, bg #f4f4f2, radius 16. EVA replies are full-width prose with the mark beside — never a bubble.

Motion

Only three animations: spark pulse (1.6s ease-in-out, opacity 1→0.4), streaming cursor blink (1s step-end), card entrance (120ms fade + 4px rise). Nothing else moves. Respect prefers-reduced-motion: pulse and cursor become static.

Language stability

BM runs ~15–25% longer than English: buttons size from content with nowrap, cards use min-height not fixed height, labels never truncate. EVA mirrors the user's language per message; UI chrome follows the app language setting only.

Accessibility

Ink on paper 15.8:1; secondary #6f6f68 5.4:1; accent on white 6.2:1 (dark mode accent lightened to keep ≥4.5:1). Hit targets ≥44px on mobile. Streaming region is aria-live="polite"; Stop is a real button, reachable by keyboard; thinking state announces "EVA is thinking".
